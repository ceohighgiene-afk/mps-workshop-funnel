# High-giene Brow Workshop Funnel

Static landing page for the High-giene Beauty Clinic & Salon eyebrow artistry workshop.

## Preview locally

Open `index.html` in a browser. The consultation form is a front-end preview only; it does not send or store submissions.

## Deploy to Vercel

Import the GitHub repository into Vercel as a static site. No build command is required. Set the output directory to `.`. Connect the final booking or contact service before using the form to collect consultation requests.
